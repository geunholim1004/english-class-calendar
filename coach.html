작동 방식

AI 연결 · 자동 전환

한 곳이 혼잡하거나 한도를 넘으면 다음 AI로 자동으로 넘어가고, 모두 막히면 오프라인 자동 판정으로 채점해요. 어떤 AI가 답했는지는 결과 아래 🤖 줄과 위쪽 표시에 나와요. 키는 이 브라우저(localStorage)에만 저장돼요.

① Google Gemini (무료)

키 받기: aistudio.google.com/apikey → API 키 만들기. 카드 등록 없음.

② Groq (무료)

키 받기: console.groq.com/keys → 구글 계정 로그인 → Create API Key. 카드 등록 없음.

③ OpenRouter 무료 모델

키 받기: openrouter.ai/settings/keys → Create Key. 충전하지 않아도 :free 모델은 무료예요.
④ Claude (유료 · 선택, 비워 두면 사용 안 함)
사용한 만큼 요금이 나가요. 넣는다면 Anthropic 콘솔에서 월 사용 한도를 꼭 걸어 두세요.
학생 기기에서 키를 따로 넣지 않아도 돼요. (Daniel도 공유 저장소를 볼 수 있어요)
