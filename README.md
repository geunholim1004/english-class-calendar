# 영어 수업 달력 & 수업료 계산기 / English Class Calendar & Fee Calculator

매주 일요일 17:00, 25분 = 1 Class, $6 선불 수업을 달력으로 관리하고
우즈벡중앙은행(CBU) 공식 환율로 UZS 수업료를 계산하는 웹 앱입니다.

## 권한
| 역할 | 방법 | 할 수 있는 것 |
|---|---|---|
| 마스터 (Edward) | 로그인 → 마스터 탭 → GitHub fine-grained 토큰 (calendar · private · share · access 4개, Contents: Read and write) | 모든 수업 처리·추가, 설정, 납부·영수증, 사용자 관리, 요청 승인/거절 |
| 사용자 (선생님) | 마스터가 아이디 발급 → 카톡 초대 → 본인 비밀번호 등록 → 아이디 로그인 | 수정·이동 **요청만** (승인 대기 저장) · 금액·납부·설정은 안 보임 |
| 그 외 | 링크만 열기 | 로그인 화면만 보임 (데이터 없음) |

- 마스터 토큰은 마스터 브라우저(localStorage)에만 저장됩니다.
- 사용자용 토큰(share · access 2개만)은 `english-class-access/users.json`에 **각자 비밀번호로 암호화**(PBKDF2 25만 회 + AES-GCM)되어 저장되며, 원문·비밀번호는 어디에도 저장되지 않습니다.
- 요청은 `english-class-share/requests.json`에 승인 대기로 쌓이고, 마스터가 승인해야 반영됩니다.

## 보안
- 화면에 그리는 모든 사용자 입력은 이스케이프 처리, 저장소에서 읽은 요청·사용자·시각 값은 형식 검증 후 사용
- Content-Security-Policy: 이 사이트의 스크립트와 api.github.com 외 연결 차단
- 검색엔진·AI 수집 거부 메타 태그 (noindex, noai 등 — 지키는 수집기에만 효과)
- 저장소 4개로 권한 분리 (최소 권한):

| 저장소 | 공개 | 내용 | 쓰기 |
|---|---|---|---|
| english-class-calendar | 공개 | 코드만 (데이터 없음) | 마스터 |
| english-class-private | 비공개 | 전체 상태·금액·납부·영수증·로그 보관 | 마스터 |
| english-class-share | 비공개 | 금액을 뺀 수업 일정, 변경 요청 | 마스터 + 선생님 |
| english-class-access | 공개 | 암호화된 사용자 정보만 | 마스터 + 선생님 |

- 선생님 토큰으로는 코드·금액·납부 저장소에 접근할 수 없습니다 (사이트가 넓은 권한의 토큰은 거부).

## 규칙
- 선불: 시작일부터 N개월 안의 일요일 수 × $6
- '당일'은 접속 위치와 관계없이 **한국 시간(KST)** 기준
- 선생님 사유 + 수업 당일 변경(이동·수정·Hold) → 패널티 보너스 1회 / 전날 이전 연락 → 패널티 없음
- 선생님 사유 취소·No-show → 맨 뒤 보강 + 패널티 보너스 1회
- 내 사유 취소·No-show: 선불 1회 차감, 보강 없음
- 내 사유 Hold: 보류만 (차감 없음) · 내 사유·사전 합의 이동: 선불 유지 (합의 기준일 미달 시 기록에 표시)
- 남은 수업이 2회가 되는 날 다음 선불 기간 금액을 알림

## 파일
- `index.html` – 화면
- `app.js` – 계산·달력·권한·GitHub 동기화
- `hub.html` · `hub.js` – 허브 (로그인·등록·매칭·결제)
- `coach.html` · `coach.js` – 🎓 AI 영어 코치 모듈 (마스터·학생 버튼으로 진입)
- `voice-coach/` – 🎙 AI 영어 **음성** 코치 모듈 (독립 폴더, 기존 파일은 건드리지 않음)
  - 주소: `https://geunholim1004.github.io/english-class-calendar/voice-coach/`
  - 달력 로그인(`eng-class-gh-auth`)을 그대로 사용 — 로그인 안 하면 로그인 안내만 보임
  - AI 키는 `coach.html`과 공유(`edward-coach-secret-v1`, 학생은 마스터가 공유한 무료 키), 한도는 `coach-limits.json`, 사용 횟수는 코치와 함께 셈
  - 실사 선생님 8명(`voice-coach/teachers/*.jpg`, 같은 이름으로 덮어쓰면 사진 교체) · 영어 억양별 목소리(Edge의 Natural 음성 권장)
  - Claude·ChatGPT·Gemini 유료 구독은 API로 연결할 수 없어, 선생님·상황 지침을 복사하고 각 앱을 열어 앱의 음성 대화로 이어감
  - 화상 모드: 사진 속 입·턱이 소리에 맞춰 움직이고 눈 깜빡임·고개 움직임(`face-anim.js`, 외부 서비스 없음). 크롬·엣지 데스크톱에서 ChatGPT·Claude 음성 탭의 소리를 공유하면 그 목소리에 맞춰 움직이고, '선생님 창 띄우기'로 항상 위 작은 창(화상통화처럼)
  - `coach.html` 헤더의 "🎙 AI 음성 코치" 단추와 선생님 작은 사진 8장(`voice-coach/?t=이름`으로 그 선생님 바로 선택)
  - 여자 선생님은 여자 영어 음성, 남자 선생님은 남자 영어 음성을 먼저 고름 (Edge의 Natural 음성 권장)
  - 달력의 "🎓 AI 영어 코치" 단추 → 바로 AI 음성 코치(말하기 대화 + 글쓰기 훈련). 처음 선생님은 Emma, 그다음엔 마지막에 고른 선생님
  - 한국어 / English 화면 전환 (달력과 같은 언어 설정 `eng-class-lang` 공유). 글쓰기 훈련 탭(기존 코치)은 아직 한국어
  - **실시간 음성 대화**(Gemini Live, `live-coach.js`·`pcm-worklet.js`): 선생님 얼굴이나 "▶ 실시간 음성 대화 시작"을 누르면 이 화면에서 바로 말하고 듣기 — 선생님 성별에 맞는 Gemini 음성, 내 말·선생님 말이 말풍선 글자로 표시, 말을 끊어도 됨. 코치의 Gemini 키(학생은 마스터 공유 키) 사용, 세션당 AI 사용 1회
  - 마스터는 음성 코치 화면의 "사진 바꾸기 (마스터)"로 선생님 사진을 바꿀 수 있음 → `voice-coach/teachers/`에 저장되어 모두에게 반영
- 데이터는 이 저장소에 두지 않습니다 (위 저장소 표 참고). 예전 `data/` 파일은 마스터 첫 접속 시 비공개 저장소로 옮겨진 뒤 삭제됩니다.

## 🤝 영어 수업 허브 (`hub.html`) — 로그인 · 등록 · 매칭 · 결제
달력 앱과 같은 저장소·같은 마스터 아이디로 동작하는 확장 모듈입니다. 주소: `https://geunholim1004.github.io/english-class-calendar/hub.html`

| 기능 | 흐름 |
|---|---|
| 로그인 | 아이디·비밀번호 하나로 마스터 / 선생님 / 학생 자동 구분 (마스터 = 달력 앱 마스터 아이디) |
| 선생님 등록 | 신청서(국가·억양·희망 수업료·경력·녹음 링크·가능 시간·분야) → 마스터 공개키로 암호화된 링크 → 카톡으로 마스터에게 → 마스터 승인(점수 채점) → 인력풀 등록 → 로그인 |
| 학생 등록 | 신청서(본인/자녀/동료·수준·1회 예산·가능 시간·목표, 자녀는 보호자 동의) → 같은 방식으로 승인 → 인력풀 |
| 매칭 | 학생별 추천 선생님 순위: 시간 겹침 40 · 목표 25 · 선생님 점수 20 · 가격 여유 15 (예산 < 수업료, 시간 불일치는 제외). 마스터가 확정하면 3개월 수업 일정·학생 청구·선생님 지급이 자동 생성 |
| 결제 | 학생 화면: 토스(toss.me) · 카카오페이 송금 링크 · 카카오뱅크 등 계좌 복사 → "송금했어요" → 마스터만 열리는 확인 링크 → 마스터 입금 확인 → 선생님 지급 차례로 전환 |
| 연장 | 남은 수업 2회가 되면 홈 '할 일'에 다음 기간 청구 안내 |

### 저장 위치
| 저장소 | 파일 | 내용 |
|---|---|---|
| english-class-private (비공개) | `hub/data.json` · `hub/keys.json` · `hub/master-key.json` | 인력풀·매칭·장부·받을 계좌, 회원 데이터 키, 마스터 개인키 |
| english-class-access (공개) | `hub/master-pub.json` · `hub/accounts.json` · `hub/p/<아이디>.json` | 마스터 공개키, 비밀번호로 잠긴 회원 키, 회원별 화면(회원 키로 AES-GCM 암호화) |

- 허브 회원(선생님·학생)은 **GitHub 토큰이 없습니다.** 자기 화면만 자기 비밀번호로 열 수 있습니다.
- 신청·송금 알림 링크는 RSA-OAEP + AES-GCM으로 암호화되어 마스터만 열 수 있고, 송금 알림은 회원 키 HMAC으로 위조를 막습니다.
- 공개 저장소에는 이름·연락처·계좌번호가 평문으로 저장되지 않습니다.
- 처음 한 번 마스터가 허브를 열면 마스터 키가 만들어지고, 그때부터 신청을 받을 수 있습니다.
- 은행 자동 출금·자동 입금 확인(PG 결제)은 사업자 등록과 결제대행 계약(토스페이먼츠·포트원 등)이 필요해 현재는 송금 링크 + 마스터 확인 방식입니다.
